핵심 요구사항 분석

  • AI 초대장·프롤로그 생성 — 사용자 이름 입력 폼, OpenAI API 기반 맞춤형 초대장·프롤로그 텍스트 생성 및 화면 출력
  • AI 역사동화·삽화 생성 — 관광지 방문·미션 수행 데이터 입력 시뮬레이션 → 맞춤형 역사동화 텍스트 생성 → 동화 내용 기반 페이지별 삽화 이미지 생성
  • PDF 전자책 자동 제작 — 생성된 동화 텍스트와 삽화 이미지를 결합하여 PDF 파일 자동 생성 및 다운로드 제공
  • AI 프롬프트 테스트 환경 — 프롤로그·동화·삽화 생성용 프롬프트 수정 기능, 변경에 따른 생성 결과 반복 테스트
  • 성능/규격 — AI 생성 파이프라인의 단계별 소요 시간 측정 및 최적화
  • 보안/인증 — 아동 부적절 콘텐츠 필터링 등 AI 유해 출력 방지 가드레일 적용
  • 산출물 — 소스 코드 원본, AI 프롬프트 세트 및 테스트 결과 보고서

제안 포인트

1. "텍스트 생성 → 이미지 결합 → PDF 자동화" 파이프라인 실전 경험 — AI가 데이터를 기반으로 문서를 생성하고, 이미지·표와 결합해 PDF로 자동 출력하는 파이프라인(HTML/이미지 → PDF 변환, 양식 채우기, 병합)을 실제 서비스에 구축한 경험이 있습니다. 본 과업의 핵심 흐름과 정확히 일치합니다.

2. OpenAI API 실전 연동 및 프롬프트 코드화 — 텍스트·이미지 생성 API를 실서비스에 연동하고, 프롬프트를 코드로 관리·버전관리하며 튜닝한 경험을 바탕으로, 요구된 "프롬프트 수정 → 결과 테스트" 환경을 견고하게 구현합니다.

3. 유해 콘텐츠 가드레일 설계 — 아동 대상 콘텐츠 특성을 고려하여, 생성 단계별 유해·부적절 출력 필터링과 검증 로직을 적용합니다. AI 출력 신뢰성 검증 경험을 반영합니다.

4. 성능 계측 내장 — 각 생성 단계(프롤로그·동화·삽화·PDF)의 소요 시간을 계측·로깅하는 구조를 내장하여, PoC의 핵심 목표인 "품질·소요 시간 검증"을 데이터로 뒷받침합니다.

5. 정부지원사업 대응 — 세금계산서 발행이 가능한 사업자로, 행정 서류 제출 및 정산 절차에 문제없이 대응합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

여주 관광 체험 플랫폼 본 구축에 앞서, 핵심 기능인 AI 기반 맞춤형 역사동화 생성, 삽화 생성, PDF 전자책 제작 파이프라인의 품질과 소요 시간을 검증하기 위한 PoC(개념 증명) 웹 페이지를 구축합니다. 본 프로젝트는 전체 플랫폼 구축이 아닌 AI 파이프라인 검증에 초점을 맞춥니다.

프로젝트 개요

VC 투자조합 관리·전자결재·규제 보고를 통합한 올인원 SaaS 플랫폼. ChatGPT API로 데이터 기반 문서를 자동 생성하고, 이미지·표·양식과 결합해 PDF로 자동 출력하는 파이프라인을 구축했습니다.

핵심 기능

  • ChatGPT API 연동 AI 투자심사보고서 자동 생성
  • 7중 PDF 문서 처리 — HTML/이미지 → PDF 변환, 양식 채우기, 병합, 편집
  • 다단계 전자결재 및 규제 보고 자동화

본 프로젝트와의 유사점
